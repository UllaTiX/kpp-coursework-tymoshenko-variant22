# Курсова робота: інформаційна система сервісного обслуговування автомобілів (Варіант №22)

Клієнт–серверна інформаційна система для управління клієнтами, автомобілями та сервісними замовленнями автосервісу. Серверна частина реалізує бізнес-логіку, валідацію, розрахунок інтегрального показника, контроль переходів станів замовлень і роботу з базою даних MySQL через DAO/JDBC, а JavaFX-клієнт забезпечує роботу з даними через HTTP/JSON та фоновий імпорт даних.

## Технології
- **Java 21**, **Maven**, **JavaFX** — мова розробки, збірка модулів і графічний інтерфейс користувача
- **Servlet API 4.0.1**, **Apache Tomcat 9.x** — HTTP-сервлети та розгортання серверного WAR-модуля
- **MySQL / JDBC**, **Jackson** — реляційне зберігання даних, доступ через DAO/JDBC та серіалізація JSON
- **JUnit 5**, **Git** — автоматизоване модульне тестування та контроль версій

## Структура репозиторію
- `README.md` — інструкція зі встановлення, збірки, запуску та перевірки проєкту
- `database.sql` — SQL-схема бази даних та початкові дані
- `server/` — серверний Maven-модуль (моделі, DAO/JDBC, сервіси, сервлети, тести)
    - `server/src/test/java/` — модульні тести JUnit 5
- `client/` — клієнтський Maven/JavaFX-модуль (клієнтські моделі, HTTP-клієнт, UI, фоновий Task)
    - `client/sample-data/` — приклад CSV-файлу для імпорту

## Підготовка бази даних
1. Встановіть і запустіть локальний сервер **MySQL** та переконайтеся, що він доступний для підключення.
2. Виконайте кореневий файл `database.sql` (через SQL-клієнт або інструмент імпорту) для створення бази даних і таблиць.
3. Перевірте наявність основних таблиць у базі даних та за потреби задайте локальні параметри підключення до БД (без зберігання реальних паролів у репозиторії).
